How it works

Three steps, one afternoon.

Point your existing client at the gateway. Nothing else in your application has to change on day one.

  1. 01

    Register a pool

    Describe where a model lives — your cluster, a vendor, or both — and TensorBlack starts health-checking it.

  2. 02

    Write one rule

    Send this class of request to that pool, with a budget and a fallback. Rules are versioned and diffable.

  3. 03

    Swap the base URL

    Change one string in your client. Traces, caching, and limits apply from the very first call.

route.py 
# 1 — point the client at the gateway
from openai import OpenAI

client = OpenAI(
    base_url="https://gw.tensorblack.io/v1",
    api_key=os.environ["TB_KEY"],
)

# 2 — name a route, not a model
reply = client.chat.completions.create(
    model="route:summarize@stable",
    messages=[{"role": "user", "content": doc}],
    extra_headers={"x-tb-team": "search"},
)

# 3 — the trace comes back with it
print(reply.tb.pool, reply.tb.cache_hit, reply.tb.cost_usd)
#  a100-eu-west   True   0.00019
